# Sofi Spanish Locale On Toph

## Goal

Keep `toph` and its other users in English while making Sofi's login and Cinnamon session use Argentine Spanish (`es_AR.UTF-8`).

## Implementation

1. Update `modules/users/sofi/default.nix` with a small `environment.loginShellInit` block guarded by `USER=sofi`.
2. In that block, export `LANG=es_AR.UTF-8` and `LANGUAGE=es_AR:es` so translated application interfaces prefer Argentine Spanish with general Spanish fallback.
3. Leave `modules/hosts/toph/configuration.nix` unchanged. Its existing `i18n.defaultLocale = "en_US.UTF-8"` continues to control other users, while its existing `es_AR.UTF-8` category settings provide Sofi's regional formatting and ensure the locale is generated.

This uses NixOS's generated `/etc/profile`, which the graphical X session wrapper sources before starting Cinnamon. It does not create or overwrite files in `/home/sofi` and does not require Home Manager.

## Verification

1. Evaluate the `toph` configuration and confirm the generated login initialization contains the guarded Sofi locale exports:
   - `nix eval .#nixosConfigurations.toph.config.environment.loginShellInit`
   - `nix eval .#nixosConfigurations.toph.config.system.build.toplevel.drvPath`
2. On `toph`, apply the configuration with `sudo nixos-rebuild switch --flake .#toph`.
3. Log Sofi out completely and back into Cinnamon, then run `locale` in her session. Confirm `LANG=es_AR.UTF-8`, `LANGUAGE=es_AR:es`, and the interface is Spanish.
4. Open a fresh session or login shell as another `toph` user and run `locale`; confirm its `LANG` remains `en_US.UTF-8`.

## Critical File

- `modules/users/sofi/default.nix` - owns Sofi-specific account and session behavior.
