# Nested Sway Test Plan

## Goal

Run Sway as one X11 window inside the current i3 session, using the existing i3-style Sway shortcuts and launching it by name from rofi. Hyprland is out of scope for this pass.

## Files

- `/home/fedex/bin/sway-nested` - executable launcher visible to rofi through `~/bin`.
- `/home/fedex/code/desktop-tests/sway/config` - nested config generated from the current `/etc/sway/config` when launched.
- `/home/fedex/code/desktop-tests/sway/sway.log` - persistent nested-session log.
- `/home/fedex/.config/i3/config` - add only the approved keyboard passthrough mode; do not add a Sway launch binding.

## Implementation

1. Create `~/code/desktop-tests/sway` as the persistent test directory.
2. Add `~/bin/sway-nested` with strict shell error handling.
3. On each launch, derive `~/code/desktop-tests/sway/config` from `/etc/sway/config` so it stays aligned with the Sway translation maintained by `modules/features/desktop/wayland.nix`.
4. While deriving the config, remove only standalone `exec` and `workspace` startup commands. Preserve the existing bindings, workspace definitions, rules, styling, and Sway-specific command translations, while avoiding duplicate desktop applications in the nested session.
5. Validate the derived config before launch, then start exactly one nested output with `WLR_BACKENDS=x11`, `WLR_X11_OUTPUTS=1`, `sway --unsupported-gpu`, and the derived config. Replace `~/code/desktop-tests/sway/sway.log` with the current run's stdout and stderr.
6. Make `~/bin/sway-nested` executable so rofi's run mode discovers it.
7. Add an i3 `sway-passthrough` mode entered with `Mod4+Shift+p` and left with `Mod4+Escape`. This is required because outer i3 otherwise intercepts the same Super shortcuts before nested Sway receives them.
8. Validate the live i3 config with `i3 -C -c ~/.config/i3/config`, then reload it with `i3-msg reload`. Do not modify the NixOS repository or rebuild the system.

## Verification

1. Run `bash -n ~/bin/sway-nested` and `sway --validate --config ~/code/desktop-tests/sway/config` after generating the nested config.
2. Launch `sway-nested` from rofi and confirm one Sway X11 window appears in i3.
3. Enter passthrough with `Super+Shift+p`; verify the existing Sway/i3 scheme inside the window, including `Super+Return`, focus/move arrows, layouts, floating, and workspaces.
4. Exit nested Sway through its existing power mode (`Super+Shift+F9`, then `e`). Use `Super+Escape` afterward to return outer i3 to its default mode.
5. Confirm no desktop autostart applications were duplicated and inspect `~/code/desktop-tests/sway/sway.log` for X11 backend or NVIDIA rendering errors.
6. Confirm the original i3 session and applications remain unaffected after Sway exits.
